# ✨ What is RedFlag Detector?

**RedFlag Detector** is a chaotic relationship investigation simulator built entirely inside a single `index.html` file.

Answer a few innocent questions about your:

- boyfriend
- crush
- talking stage
- situationship
- emotional mistake

Then watch the app professionally explain why he's probably a red flag.

Even when he isn't.
